STEP-BY-STEP WORKFLOW

What You Will Do

Five milestones from orientation to final submission. Drag or use the controls to move through the sequence.

1
In Progress

Orientation

Live intro to CIPHER, a workflow demo, and a quick Q&A.

  • Introduction to CIPHER and the recruitment context.
  • Live projector demo — watch the full workflow once before you build.
  • Ask any questions before the countdown begins.
2
Setup

Environment Setup

Open your IDE, sign in with Google, create your workspace folder.

  • Open Antigravity and sign in with your Google account.
  • Create a folder named exactly TTR_[Last 3 digits of PRN].
  • Inside that folder, create docs.md or logs.txt — your prompt log.
3
Build

Prompt & Build

You lead — the AI assists. Every prompt you give goes into your log.

  • Direct the AI with clear, structured prompts. Copy each one to your log file.
  • Use any technology you're comfortable with — HTML/CSS/JS, React, Node, anything.
  • Get the core working first; polish later.
4
Deploy

Push & Deploy

Commit to a public GitHub repo and ship a live URL.

  • Initialize Git, commit all files, push to a public GitHub repository.
  • Deploy on Vercel, Netlify, or GitHub Pages — get a shareable live link.
  • Add a quick README covering your stack and features.
5
Submit

Submit

Share your GitHub link, live URL, and prompt log before time runs out.

  • Public GitHub repository URL (must be visible to anyone).
  • Live deployed app URL — test it works before submitting.
  • Your complete docs.md / logs.txt prompt log.

Setup Guidelines & Submissions

Conventions you must follow to ensure your submission is valid and evaluable.

Folder Naming Convention

Mandatory
Required Format:
TTR_<Last 3 Digits of PRN>
Example: PRN 22310123 → TTR_123

Create this folder at the start. Do all your work inside it — this is the folder you submit.

Prompt Logging Document

Core Evaluation Metric
File Name:
docs.md or logs.txt
Record every AI prompt in chronological order

After every prompt you give the AI, paste it here. This shows us how you think, structure requirements, and iterate.

Technology Freedom

Your Choice

You are free to use any technology you are comfortable with.

HTML / CSS / JS React Vite Node.js Tailwind Any framework

Pick the stack you know best and can move fastest with. Speed and completeness matter — don't start a setup you haven't done before.
